# talking-head-reel

A talking-head editing skill with an expressive, clear preset: natural,
expressive takes, readable phrase captions, a few useful visuals, and
purposeful framing changes. Memes, automatic cut sounds, and frozen
promotional end cards are off by default. The technical workflow still
transcribes every take and cuts on word timestamps.

Read [the editing style guide](references/editing-style.md) for the voice and
platform adaptations. Before a new video edit, propose an outline, then
make a short preview for review according to the existing approval scope.

## What you need

- macOS with `ffmpeg` (`brew install ffmpeg`)
- the `openai-whisper` CLI (`pip install openai-whisper`; the `turbo`
  model downloads about 1.5 GB the first time)
- Node 20 or newer
- [Claude Code](https://claude.com/claude-code)

## Install

Copy this repository's HTTPS URL from the Code menu and substitute it below.

```bash
git clone "<repository-url>" ~/.claude/skills/talking-head-reel
cd ~/.claude/skills/talking-head-reel/remotion && npm install
```

Then, in Claude Code, hand it your recording:

> Use talking-head-reel to edit ~/Downloads/IMG_1234.MOV for Instagram.
> Use the default style: preserve my energy and gestures, remove restarts,
> and add readable captions and a few helpful visuals. Propose the
> outline first, then show me a short preview before the full edit.

Paste the script you meant to say if you have one; it helps the take
selection. Rendering time depends on the video and machine; the short preview comes
before the full edit unless already waived.

## How it works

1. `scripts/prep.sh` transcodes the portrait MOV to 1080x1920 at 30 fps so
   Remotion can seek it cheaply.
2. `scripts/transcribe.py` runs whisper with word timestamps on the whole
   recording and prints the table of everything you said, every take.
3. Claude picks the best take of each sentence
   (`references/take-selection.md`) into `reel-segments.json`;
   `scripts/cut.py` turns that into captions in edit time and a timeline.
4. Claude proposes the visual beats and uses the restrained example in
   `assets/Reel.example.tsx`: steady captions, simple cards, and a few
   framing changes. More elaborate components remain optional.
5. `scripts/stills.sh` renders check frames. After the short preview review,
   `scripts/render.sh` renders the full reel; the result is checked for
   caption readability, sound, and destination UI overlap.

## What is in the box

- `SKILL.md`: the instructions Claude follows.
- `scripts/`: prep, transcribe, cut, stills, render, contact sheet.
- `assets/`: an example timeline and cut (placeholder timings of a
  fictional recording, so they compile), the overlay components.
- `references/`: the default style, take selection, recording geometry, and
  platform-specific preview checks.
- `remotion/`: a minimal Remotion 4 project with the components, the
  [Geist](https://vercel.com/font) fonts (SIL OFL 1.1), a small sound kit
  generated by `remotion/scripts/make_sfx.py`, and logos from
  [simple-icons](https://simpleicons.org) (CC0).

## Notes

- The example timeline expects a recording at
  `remotion/public/talk/ig1080.mp4`; it is not in the repo. The included
  timeline and claims are fictional examples, not the creator's experiences.
  Replace them using the pipeline on your own recording.
- The default example needs no meme assets. Optional media must have
  suitable usage rights and fit an approved edit outline.
- Paths in `SKILL.md` that say `src/`, `public/` or `out/` are inside
  `remotion/`.
